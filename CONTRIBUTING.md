# Contributing Guide

Thank you for your interest in the project! We welcome improvements, new programs, and bug fixes. Please read the guidelines below before submitting your contribution.

## 📝 Program Requirements

To be included in the system, your program must be written in one of the following languages:

- **Assembly (NASM, FASM, GAS)**
- **C**
- **C++**

The code must build within the existing build system (e.g., `build-linux.sh` or `Makefile`), or you must provide build instructions.

## 📮 How to Submit Code

You can send your code using one of these methods:

- **Telegram:** [@Egor_B_2016](https://t.me/Egor_B_2016)
- **E-mail:** `lcp.yourename@internet.ru`

## ⏳ If the author does not respond

We do our best to reply to every message, but sometimes we may be busy.  
If you haven't received a response within **7–10 days**, please **remind** us.  
We will definitely review your contribution!
